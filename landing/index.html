02 What is Chakram

A New Kind of
EVM Blockchain

Chakram is a Layer 1 blockchain that cleanly separates consensus from execution. CometBFT v0.40 handles validator coordination and instant BFT finality; go-ethereum v1.17 handles smart contracts and EVM execution.

Once a block is committed by >⅔ of active validators, it is final — forever. No probabilistic finality, no long confirmation waits, no chain reorgs. Your transactions are either in or out, within seconds.

01

Consensus

CometBFT v0.40 runs PBFT-style BFT rounds. >⅔ of active validators must sign a block before it's committed. One missed round → timeout, next proposer takes over.

02

Execution

go-ethereum v1.17 processes every EVM transaction identically to Ethereum. The same opcodes, precompiles, and gas rules — just different consensus underneath.

03

Engine API

CometBFT drives geth via engine_forkchoiceUpdatedV3 + engine_newPayloadV3 — the same bridge Ethereum uses. JWT-authenticated over localhost.

04

Staking Registry

A Solidity smart contract governs the full validator lifecycle: registration, stake, reward routing, and slashing — entirely on-chain and verifiable.

⚖️

Proportional Voting Power

1 CHK staked = 1 unit of CometBFT voting power. Your influence over consensus is exactly proportional to your stake, capped at 100,000 CHK per validator to prevent any single node from dominating.

🏷️

Validator Identity

Validators register a name, institution type (university, company, government, etc.), and website on-chain. Identity is fully optional, stored on the staking contract, and readable by any dApp without trust.

🔄

Auto State Sync & Recovery

On first run the node downloads a chain snapshot so you sync to the tip in seconds, not days. If a node falls more than 500 blocks behind it auto-wipes and resyncs — no manual intervention needed.

📜

Validator Set Governance

Stake-weighted on-chain vote to open the validator set — 66% quorum, 7-day voting window, 30-day cooldown between proposals.

🌐

Permissionless Transition

Validator set opens automatically once 548 days elapse, 20 active validators are reached, or a 66% governance vote passes.

📊

Slashing & Jailing

Misbehaving validators are slashed and jailed by the ABCI layer. Configurable burn percentage; jailed validators must unjail to re-enter.

💎

Delegation Registry Planned

CHK holders will delegate to validators and earn commission-adjusted rewards. Commission rates (0–100%) are already stored on-chain.

🔑

Validator Metadata

Each validator registers a name, website, and commission rate on-chain — readable by any smart contract or front-end without trust.

🔒

On-Chain Staking Registry

All validator registration, stake management, reward routing, and slashing are governed by a transparent Solidity contract — no off-chain trust required.

05 Run a Node

Become a Validator

A single binary — no Docker, no installer. Works on Windows, Mac, Linux, or any VPS. Up and running in under a minute.

01

Download chakram-node

One file, no installer. Pick your platform:

🐧 Linux amd64 🐧 Linux arm64 🍎 macOS Apple Silicon 🍎 macOS Intel 🪟 Windows x64 🔐 checksums .txt
02

Run it

# Linux / macOS chmod +x chakram-node && ./chakram-node
# Windows (PowerShell) .\chakram-node.exe
On first run it downloads geth, fetches genesis, generates your validator keys, and opens the dashboard at localhost:8080 — fully automatic.
03

Get your wallet address

Your node generates a unique EVM wallet on first run. Print it with:

chakram-node wallet

This prints your address and private key. Keep the private key safe — it signs your staking transactions.

04

Apply for whitelist

During the permissioned phase, the Chakram Foundation must whitelist your EVM address before you can register. Send your address to the team — once added, the Staking tab at localhost:8080 will automatically show the registration form.

The dashboard polls whitelist status every 10 seconds — no manual refresh needed.
05

Register as a validator

Once whitelisted, stake CHK and register. Two ways:

Dashboard Staking tab at localhost:8080
CLI chakram-node register --stake 1
Min stake 1 CHK
Reward 5 CHK per block

Requirements

Windows 10+ macOS 11+ Linux 4 GB RAM 50 GB disk Ports 26656 & 30303 for servers

CLI Reference

./chakram-node Start node
./chakram-node status Height + peers
./chakram-node stop Graceful shutdown
🖥️

Running 24/7 on a server?

Drop the Linux binary on any VPS — GCP, Hetzner, DigitalOcean — and run as a systemd service. Same binary, no Docker.

Download chakram-node

Become a seed node

Seed nodes are well-known entry points that help new validators discover the network. If you run on a VPS with a static IP, consider registering — it strengthens the network for everyone.

Optional · Servers only
1

Get your node addresses

Open your dashboard → Node Info. Copy your Geth Enode and CometBFT Peer addresses.

2

Publish a DNS seed

Add TXT records to any domain you control (e.g. seeds.yourorg.com):

geth=enode://PUBKEY@your-ip:30303 comet=NODEID@your-ip:26656 api=https://your-dashboard-url
3

Register with the network

Contact the Chakram team to add a link=seeds.yourorg.com TXT entry to seeds.chakram.one. Every new node will discover your seed automatically — no binary updates required.
