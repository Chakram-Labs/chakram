What is Chakram

A New Kind of
EVM Blockchain

Chakram is a permissionless Layer 1 blockchain that separates consensus from execution. CometBFT handles validator coordination and instant BFT finality; go-ethereum handles smart contracts and EVM execution.

Once a block is committed by >⅔ of validators, it is final — forever. No probabilistic finality, no long confirmation waits, no chain reorgs. Your transactions are either in or out, within one second.

Architecture

How Chakram Works

A clean separation between consensus and execution gives Chakram both the security of BFT finality and the flexibility of a full EVM.

Consensus

CometBFT v0.40 runs PBFT-style BFT rounds. >⅔ weighted stake must sign a block before it's committed. One missed round → timeout, next proposer takes over.

Execution

go-ethereum v1.17 processes every EVM transaction identically to Ethereum. The same opcodes, same precompiles, same gas rules — just different consensus underneath.

Engine API

CometBFT talks to geth via the same Engine API that Ethereum's beacon chain uses: engine_forkchoiceUpdated + engine_newPayload.

Staking Registry

A Solidity smart contract on-chain governs the entire validator lifecycle: registration, delegation, reward distribution, and slashing — fully transparent.

Run a Node

Become a Validator

Anyone can run a Chakram full node and become a validator. Choose the setup that fits your machine.

1

Download chakram-node

Grab the binary for your platform from the GitHub releases page. It's a single file — no installer needed.

🐧 Linux (amd64) 🍎 macOS (Apple Silicon) 🪟 Windows (x64)
2

Run it

# Linux / macOS chmod +x chakram-node && ./chakram-node
# Windows (PowerShell) .\chakram-node.exe
3

First-run bootstrap (fully automatic)

On the very first start, chakram-node handles everything:

  • Downloads geth for your platform from GitHub
  • Fetches the genesis block from node.chakram.one
  • Initialises chain data and generates your validator keys
  • Connects to peers and starts syncing
  • Opens your browser to localhost:8080
4

Register as a validator

Once your node is synced, go to the Staking tab at localhost:8080, stake CHK, and register. Your node starts earning block rewards immediately.

What you need

  • Windows 10+, macOS 11+, or Linux
  • 4 GB RAM · 50 GB free disk
  • Internet connection (geth P2P — port 30303 outbound)
  • CHK to stake (not required just to sync)

Useful commands

./chakram-nodeStart
./chakram-node statusHeight + peers
./chakram-node stopGraceful shutdown
./chakram-node --helpAll options

Data stored in ~/.chakram-node on Mac/Linux or %APPDATA%\chakram-node on Windows.

Download chakram-node →
1

Provision a server

Any Linux VPS — GCP, AWS, Hetzner, DigitalOcean. Install Docker and Docker Compose. Open inbound ports:

  • 26656 — CometBFT P2P (consensus)
  • 30303 — Geth P2P (execution)
2

Clone and bootstrap

git clone https://github.com/Chakram-Labs/chakram cd chakram/docker bash setup.sh --mode fullnode \ --network-url https://node.chakram.one

Downloads genesis, peers, and initialises chain data.

3

Start the node

docker compose --profile fullnode up -d

Dashboard at http://<your-ip>:8080. Live logs:

docker compose --profile fullnode logs -f
4

Register as a validator

Open the Staking tab on your dashboard once synced. Stake CHK and register — you're in the active set immediately.

Server requirements

  • Ubuntu 22.04+ (or any Linux with Docker)
  • 4 vCPU · 8 GB RAM · 100 GB SSD
  • Docker 24+ & Docker Compose v2
  • Inbound TCP 26656 and 30303 open

Useful commands

docker compose --profile fullnode up -dStart
docker compose --profile fullnode logs -fLogs
docker compose --profile fullnode downStop
curl localhost:8080/api/statusSync check

Peer info, genesis URL, and enode are on the Settings page of the explorer.
